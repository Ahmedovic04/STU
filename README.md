# نظام استدعاء طلاب السيارات الخاصة
## School Private Car Dismissal System

---

## 📦 محتويات المشروع

```
school-dismissal/
├── index.php                 ← صفحة تسجيل الدخول الرئيسية
├── database.sql              ← ملف قاعدة البيانات (شغّله أولاً)
├── includes/
│   ├── config.php            ← إعدادات قاعدة البيانات
│   └── header.php            ← الهيدر المشترك (CSS الأساسي)
├── api/
│   ├── auth.php              ← API تسجيل الدخول/الخروج
│   └── data.php              ← API البيانات (طلاب، صفوف، استدعاء)
├── admin/
│   └── index.php             ← واجهة المدير (صلاحيات كاملة)
├── management/
│   └── index.php             ← واجهة الإداري (استدعاء الطلاب)
├── teacher/
│   └── index.php             ← واجهة المعلم (بدون تسجيل دخول)
└── assets/
    └── js/
        └── common.js         ← JavaScript مشترك
```

---

## 🚀 خطوات التثبيت

### 1. متطلبات الخادم
- PHP 7.4 أو أعلى
- MySQL 5.7 أو MariaDB 10.3+
- Apache أو Nginx
- مكتبة PDO ممكّنة

### 2. نقل الملفات
```
ضع مجلد school-dismissal داخل:
- XAMPP: C:/xampp/htdocs/
- WAMP:  C:/wamp64/www/
- Linux: /var/www/html/
```

### 3. إنشاء قاعدة البيانات
```sql
-- افتح phpMyAdmin أو MySQL CLI ثم شغّل:
source /path/to/school-dismissal/database.sql
```

أو من MySQL CLI:
```bash
mysql -u root -p < database.sql
```

### 4. تعديل إعدادات الاتصال
افتح الملف `includes/config.php` وعدّل:
```php
define('DB_HOST', 'localhost');   // عنوان الخادم
define('DB_NAME', 'school_dismissal');
define('DB_USER', 'root');        // اسم مستخدم MySQL
define('DB_PASS', '');            // كلمة مرور MySQL
define('SITE_URL', 'http://localhost/school-dismissal'); // عنوان الموقع
```

### 5. تصفح الموقع
- افتح: `http://localhost/school-dismissal/`

## 🎯 الاستخدام

### واجهة المدير (admin)
- إضافة/حذف الصفوف الدراسية
- إضافة/تعديل/حذف الطلاب
- إدارة حسابات المستخدمين (إداريين)
- مشاهدة سجل الاستدعاءات اليومي

### واجهة الإداري (management)
- اختيار الصف
- اختيار الطالب والضغط على بطاقته لاستدعائه
- مشاهدة سجل استدعاءات اليوم

### واجهة المعلم (teacher)
- **لا تحتاج تسجيل دخول**
- اختيار الصف الذي يدرّس فيه المعلم
- مشاهدة قائمة الطلاب
- الطلاب المستدعون تظهر بطاقتهم باللون الأحمر مع وقت الاستدعاء والمستدعي
- **تحديث تلقائي كل 10 ثواني**
- إشعار فوري عند استدعاء طالب جديد

### إعادة التهيئة اليومية
- النظام يعمل بنظام **تاريخ اليوم** تلقائياً
- كل يوم جديد = سجل نظيف جديد بدون أي تدخل يدوي
- يتم الاحتفاظ بالسجل التاريخي في قاعدة البيانات

## 🔧 تخصيص إضافي

### تغيير فترة التحديث التلقائي (واجهة المعلم)
في ملف `teacher/index.php`، ابحث عن:
```javascript
setInterval(() => { if (selectedClassId) loadStudents(); }, 10000);
```
غيّر `10000` (10 ثواني) حسب الحاجة.

### تغيير اسم الموقع
في `includes/config.php`:
```php
define('SITE_NAME', 'نظام استدعاء الطلاب');
```
