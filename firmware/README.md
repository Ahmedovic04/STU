# 📡 دليل تشغيل جهاز استدعاء الطلاب بالبطاقة الذكية RFID (ESP32 + RC522)

هذا الدليل يشرح كيفية ربط وتشغيل جهاز الاستدعاء الإلكتروني الميداني والمخصص لبوابة المدرسة، بحيث يستطيع ولي الأمر مسح بطاقته ويتم استدعاء الطالب عند المعلم فوراً دون الحاجة لتدخل أي موظف إداري.

---

## 🛠️ القطع المطلوبة (Hardware Components)
1. **ESP32 DevKitC V4** (أو أي لوحة تطوير ESP32 30/38 pin).
2. **قارئ بطاقات RFID RC522** (تردد 13.56MHz SPI).
3. **بطاقات أو ميداليات RFID Mifare 1K / Ultralight**.
4. **جرس تنبيه Buzzer (Active Buzzer)** (اختياري - لإصدار نغمات التأكيد).
5. **ليد أخضر وليد أحمر + مقاومتين 220Ω** (اختياري - لمؤشرات الحالة).
6. أسلاك توصيل Dupont (أنثى إلى ذكر / أنثى إلى أنثى).

---

## 🔌 مخطط توصيل الأسلاك (Wiring Diagram)

### 1. توصيل قارئ RC522 بـ ESP32:
| منفذ RC522 | منفذ ESP32 DevKitC | ملاحظات هامة |
| :--- | :--- | :--- |
| **SDA (SS)** | **GPIO 5** | خط اختيار الشريحة (SPI Chip Select) |
| **SCK** | **GPIO 18** | خط الساعة (SPI Clock) |
| **MOSI** | **GPIO 23** | خط إرسال البيانات (Master Out) |
| **MISO** | **GPIO 19** | خط استقبال البيانات (Master In) |
| **IRQ** | *غير متصل (N/C)* | لا يلزم توصيله |
| **GND** | **GND** | الأرضي المشترك |
| **RST** | **GPIO 22** | إعادة التعيين (Reset) |
| **3.3V** | **3V3 (3.3V)** | ⚠️ **تحذير: لا توصله بـ 5V إطلاقاً حتى لا يحترق القارئ!** |

### 2. توصيل التنبيهات (Buzzer & LEDs) [اختياري]:
- **Buzzer (+)**: موصل بـ **GPIO 4** (والطرف السالب بـ GND).
- **LED الأخضر (+)**: موصل بـ **GPIO 2** عبر مقاومة 220Ω (والسالب بـ GND).
- **LED الأحمر (+)**: موصل بـ **GPIO 15** عبر مقاومة 220Ω (والسالب بـ GND).

## 💻 خطوات رفع الكود على ESP32 (Arduino IDE)

1. افتح برنامج **Arduino IDE**.
2. ثبّت دعم لوحات ESP32 (من Tools -> Board Manager وابحث عن `esp32` بواسطة Espressif).
3. ثبّت المكتبات التالية من **Library Manager**:
   - `MFRC522` (بواسطة GithubCommunity / miguelbalboa)
   - `ArduinoJson` (بواسطة Benoit Blanchon - الإصدار 6 أو 7)
4. افتح الملف:
   `firmware/esp32_rc522/esp32_rc522_caller.ino`
5. عدل البيانات الآتية في أعلى الكود:
   ```cpp
   const char* WIFI_SSID     = "اسم_شبكة_الواي_فاي";
   const char* WIFI_PASSWORD = "كلمة_المرور";
   const char* SERVER_URL    = "http://رابط_سيرفر_المدرسة/api/rfid_call.php";
   ```
6. اختر اللوحة: `ESP32 Dev Module` واختر منفذ الـ COM الخاص بك.
7. اضغط **Upload** لبرمجة القطعة.

## 👨‍💼 كيفية ربط بطاقة جديدة لأي طالب من لوحة الإدارة
1. ادخل إلى لوحة تحكم الإدارة: `/admin/`.
2. انتقل إلى **إدارة الطلاب**.
3. يمكنك ربط البطاقة بطريقتين:
   - **طريقة 1:** اضغط على زر **"📡 ربط بطاقات RFID"** في أعلى القائمة، اختر الطالب، ثم اكتب أو امسح كود البطاقة واضغط حفظ.
   - **طريقة 2:** اضغط على زر التعديل (✏️) بجانب أي طالب، واكتب كود البطاقة في حقل **"بطاقة RFID الذكية"**.
